# Rocket

Fly a rocket through asteroids and space junk. Grab the stars, dodge the rest, see how far
you get. Drag to steer on a phone, or use the mouse, arrow keys or WASD.

The whole game is `index.html`: no dependencies, no network, nothing stored. Vite is only
here so the portfolio can build it and serve it from `/rocket/`.

```bash
npm install
npm run dev
```
